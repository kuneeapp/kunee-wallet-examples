# KUNEE Wallet Examples

This folder is a **documentation-only sample** showing how to discuss wallet review concepts without providing wallet software. Its purpose is to give contributors a safe pattern for fictional, non-actionable examples. It contains no application source, runnable integration, or instructions to connect a wallet or handle funds.

## Contents

- [Synthetic review example](./EXAMPLE.md) — fictional, offline-only transaction-review copy and a safety checklist.
- [Contributing](./CONTRIBUTING.md) — rules for adding or revising sample material.
- [Security](./SECURITY.md) — sensitive-data exclusions and reporting guidance.
- [Changelog](./CHANGELOG.md) — planned documentation updates.

## Status and safe use

The documentation-only preview is not a wallet software release. The example values are invented and must not be treated as addresses, live transaction data, or production guidance. Never add seed phrases, private keys, user information, RPC credentials, or real transaction records.

Any referenced contract activity is **operator-only testing** and does not establish public availability or a public-use workflow. For contract information, see only the [deployment record](https://github.com/kuneeapp/kunee-contracts/blob/main/DEPLOYMENTS.md).
