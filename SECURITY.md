# Wallet example security

This documentation-only sample is intended for learning material. It does not provide a wallet implementation, a safe transaction workflow, or assurance that any example is suitable for handling assets.

## Report an issue

Report accidental exposure or a security concern privately to [support@kunee.app](mailto:support@kunee.app). Include enough context to locate the issue, but do not send secrets or personal information. Avoid publishing details of an unresolved issue or testing systems without authorization.

## Do not contribute

- Real seed phrases, private keys, keystore files, passwords, or API credentials.
- Real wallet addresses or data that can identify a person.
- Instructions or code that sign, broadcast, or deploy transactions.

Contract references describe operator-only testing, not public availability. The only contract-information reference is the [deployment record](https://github.com/kuneeapp/kunee-contracts/blob/main/DEPLOYMENTS.md).
