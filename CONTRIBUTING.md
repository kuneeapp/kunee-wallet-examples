# Contributing wallet examples

Contributions should make wallet concepts easier to understand without inviting use with real accounts or funds. This repository is sample-only documentation; it is not an approved wallet SDK or integration.

By contributing, you agree to license your contributions to this repository under its [MIT License](./LICENSE). Only contribute work you have the right to license; this does not license the KUNEE application or its trademarks.

## Review checklist

- Use fictional accounts, addresses, balances, and transaction identifiers.
- Never include recovery phrases, private keys, signing material, secrets, or real user data.
- Do not add live RPC endpoints, external deployment scripts, or instructions to submit transactions.
- Label pseudocode and non-runnable snippets clearly; avoid language suggesting security guarantees.
- Keep contract references within the documented operator-only test scope. Use the [deployment record](https://github.com/kuneeapp/kunee-contracts/blob/main/DEPLOYMENTS.md) for contract details.

Describe the intended reader and any limitations in each proposed example. If a sample could be mistaken for production code, revise it before proposing the change.
